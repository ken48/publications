Инструкция для агента.

Этот файл описывает структуру системы заметок. Используй его, чтобы знать, где лежат данные, как они организованы и как связаны между собой.

## Структура папок

```
raw/
└─ YYYY/
   └─ MM/
      └─ YYYY-MM-DD Topic.md
      └─ YYYY-MM-DD HH-mm-ss.md

retros/
└─ YYYY/
   └─ YYYY-MM.md
   └─ YYYY.md
```

## Raw

Единое пространство для всех записей: заметки, личный дневник, рабочий лог. Всё в одной папке, без разделения по типу.

Имя файла — единственная классификация:

- Есть тема — `YYYY-MM-DD Topic.md`.
- Нет темы — `YYYY-MM-DD HH-mm-ss.md`.

Теги минимальные и только для фильтрации:

- `#work` — рабочая запись.
- `#public` — заметка потенциально годится для публикации.

Записи без тегов — личные и непубличные по умолчанию.

## Связь между записями

Явных ссылок и тематических тегов между записями нет. Связь восстанавливается через хронологию: что было рядом по времени, то и связано. Если нужно понять контекст заметки — ищи другие записи за ту же дату или ближайшие дни.

## Retros

Ретроспективные срезы, которые сжимают записи из raw.

- Monthly — обзор за месяц. Источники: все записи из raw за соответствующий месяц.
- Yearly — обзор за год. Источники: все monthly за соответствующий год.

В ретроспективах добавляется тег `#agent` с указанием модели.

## Как искать информацию

- По конкретной дате: все файлы из raw с этой датой в имени.
- По теме за период: полнотекстовый поиск по raw за нужный период. Не полагаться на теги — одна и та же тема может быть сформулирована по-разному в разное время.
- По рабочему контексту: фильтровать по тегу `#work` за нужный период.
- За длинный период: начинать с monthly/yearly, углубляться в raw только при необходимости.

## Что важно помнить

- Система намеренно минималистична. Записи не связаны ссылками и не размечены тематическими тегами.
- Не пытайся восстанавливать связи через теги или категории — ищи по времени и содержанию.
- В raw лежат записи разного характера (заметки, дневник, рабочий лог) без формального разделения. Тип записи определяется по содержанию, а не по метаданным.
- Отсутствие записи за конкретный день — это не ошибка, а отсутствие материала.
- При проведении ретроспективы конкретные вопросы и фокус задаются в запросе. Эта инструкция описывает только где и как лежат данные.
